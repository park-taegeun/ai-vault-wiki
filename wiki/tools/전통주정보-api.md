## 한 줄 정의
공공데이터포털(odcloud)의 "전통주정보"(15048755) API다. 전국 양조장의 전통주 제품 1,215행을 준다. [[관광데이터-공모전]]에서 주종·맛 정보의 유일한 소스로 썼다.

## 핵심 내용
- **엔드포인트**: Base `https://api.odcloud.kr/api/15048755/v1`, uddi `uddi:f60051e9-9730-4686-b4df-a45a84e8a849` (전통주정보_20241231). OAS 문서의 3개 버전 중 최신인 20241231을 골랐다.
- **페이지네이션**: `page` / `perPage`. `perPage=1000` × 2페이지로 전건을 받는다.
- **인증**: serviceKey는 셸 환경변수로 주입한다. 값은 `<REDACTED>`.
- **필드 12개(전부 한글 키, 모두 string)**: 제품명, 제품소개, 알콜도수, 용량, 성분, 특이사항, 특징, 판매여부, 양조장, 양조장주소, 홈페이지주소, 수상경력
- **'주종' 컬럼이 없다** (실측 확인). 주종은 텍스트에서 파생 태깅해야 한다 → [[텍스트-키워드-태깅]]
- **사진 필드도 없다**: 제품 1,215건이 전부 텍스트다. 술 사진은 이 API로는 확보할 수 없다 → [[공공누리]]

### 데이터 현황 (실측)
- totalCount 1,215 = 1페이지 1,000 + 2페이지 215. 페이지 경계 중복 0, 완전 동일 행 0, 누락 0.
- 판매여부: Y 1,188 / N 27 / null 0 → 2-state로 충분하다. N 27건은 노출 정책이 필요하다.
- (제품명, 양조장) 중복 키 13건. totalCount는 "행 수"지 "제품 수"가 아니다.
- 양조장 유니크: 법인격(㈜·농업회사법인 등)까지 정규화하면 **448곳** → [[이름-정규화-조인]]
- **설명이 79자에서 잘린다**: 59곳에 연결된 술 기준으로 술 설명 366개 중 331개(91%), 특징 문장 323개 중 93개(29%)가 잘려 있다.

### 결정과 이유
- **주종 소스로 확정**: [[찾아가는양조장-api]]에는 주종이 없고, 체험프로그램 API(15089109)는 1건뿐이라 뺐다.
- **주종 추론에서 성분 필드를 빼고, 청주는 단어 경계로 찾는다**: 첫 추론에서 성분(원재료)의 과일 첨가물이 과실주로 새고, '청주'가 제품명 부분 문자열·비유문("청주와 같은")·'소주' 제품에 잘못 걸렸다. 재추론 결과는 [[텍스트-키워드-태깅]] 참조.
- **잘린 설명은 지어서 채우지 않는다**: 뒷부분을 생성하면 없는 내용을 지어내는 것이고, 술 설명이라 사실과 다르면 문제가 된다. 대신 마지막 마침표 뒤의 잘린 조각만 버릴 수 있다. 235개는 이렇게 깔끔해지고, 마침표가 하나도 없는 96개는 그대로 두거나 숨기는 수밖에 없다.
- **한글 키는 영문 매핑 레이어를 거친다** (예: 제품명 → `product_name`). 원본 키가 바뀌면 그 레이어만 고치면 된다.

## 언제 쓰나 (상황 예시)
- 양조장별 대표 제품·도수·주종을 보여 줄 때.
- 맛·향 태그를 만들 원천 텍스트(특징·제품소개)가 필요할 때. 다만 특징 컬럼만으로는 부족하다(아래).

## 실습에서 배운 것 / 트러블슈팅
- **특징 컬럼은 사실상 음식 페어링 안내다**: 찾아가는양조장에 조인된 제품 363건(포함 매칭 기준) 중 60.9%(221건)에는 맛·향 표현이 아예 없다(빈값 39 + 페어링·역사·도수만 182). 동의어 사전을 다 갖춰도 자동 태깅 상한은 39.1%다 → [[텍스트-키워드-태깅]]
- **수상 문구는 최신 1개만 뽑으면 안 된다**: 수상 문구가 있는 술은 366개 중 77개이고, 그중 35개는 여러 상이 적혀 있다. 오래된 상이 더 높은 경우가 많고, 술 상이 아닌 표창이 섞여 있으며, 연도가 없거나 79자에서 잘려 무슨 상인지 모르는 문구도 있다.
- **원본 오류**: 판매 중단 표시가 있는 술 10개가 섞여 있고(2개는 이름에 "단종"이 박혀 있음), 같은 술이 두 줄로 들어온 곳이 6곳, 띄어쓰기가 전혀 없는 설명이 1건 있다.
- **홈페이지 필드**: 한글 도메인·punycode·SNS 링크가 섞여 있어 검증·정규화한 뒤 노출해야 한다.
- 교차검증은 두 세션이 서로의 결과를 재현하는 방식(적대적 재현)으로 했다 → [[ai-산출물-검증]]
