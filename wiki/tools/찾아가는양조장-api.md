## 한 줄 정의
공공데이터포털(odcloud)의 "찾아가는양조장정보"(15048756) API다. 방문할 수 있는 양조장 59곳의 이름·주소·홈페이지·방문 가능 여부를 준다. [[관광데이터-공모전]]에서 양조장 목록의 기준 데이터로 썼다.

## 핵심 내용
- **엔드포인트**: Base `https://api.odcloud.kr/api`, 경로 `/15048756/v1/uddi:60ae9d09-1e96-4636-b735-9346089d3160` (찾아가는양조장정보_20241231, 최신본)
- **페이지네이션**: `page`, `perPage`, `returnType=JSON`. `perPage=100`이면 한 번 호출로 전건을 받는다.
- **인증**: `serviceKey`는 셸 환경변수로 넣고 `--data-urlencode`로 보낸다. 키 값은 `<REDACTED>`.
- **응답 envelope**: `currentCount`, `matchCount`, `page`, `perPage`, `totalCount`, `data[]`
- **필드 7개(키가 전부 한글)**: 상호명, 주소, 홈페이지, 상시방문가능여부(Y/N·null), 예약방문가능여부(Y/N·null), 사용여부(Y/N), 조회수(number)

### 데이터 현황 (실측)
- 총 59건 (totalCount와 data 길이 일치)
- 사용여부: Y 59 / N 0 → 사실상 의미 없는 컬럼
- 상시방문가능여부: Y 35 · N 15 · null 9
- 예약방문가능여부: Y 24 · N 4 · null 31 (52%가 비어 있음)
- 원본 데이터는 2024년 12월 기준이고, 차기 등록이 2026-08-08로 예고돼 있었다 → [[수기-보정-레이어]]

### 지역 매핑
- 주소의 **첫 공백 토큰**을 표준 시도로 정규화한 뒤 광역권으로 묶었다(`경기`/`경기도`, `충북`/`충청북도` 같은 변형 흡수). 지오코딩 없이 59/59(100%) 성공했고 실패·애매한 경우는 0건이었다.
- 6광역권: 충청 17 · 경상 16 · 수도권 13 · 전라 8 · 강원 3 · 제주 2
- 시도로 나누면: 경기 11, 충북 11, 경북 11, 충남 6, 전남 5, 강원 3, 경남 3, 전북 3, 인천 2, 제주 2, 부산 1, 울산 1. 대구·대전·광주·세종·서울은 0건이다.

### 결정과 이유
- **주종 소스는 [[전통주정보-api]] 하나로**: 이 API에는 주종 컬럼이 없다. 체험프로그램 API(15089109)는 데이터가 전체 1건뿐이라 뺐다.
- **양조장명 정규화 조인으로 주종을 연결**: 59곳 중 56곳(94.9%)이 매칭됐다 → [[이름-정규화-조인]]
- **지역 칩**: 분석은 6광역권 유지를 권고했다. 명세의 8칩(부산·울산 독립)으로 가면 부산·울산 탭이 각 1건뿐이라 빈 탭에 가깝고, 대구 0·대전 0인 다른 광역시와 기준이 어긋난다는 이유였다. 최종적으로는 명세의 8칩을 그대로 받아들였다(이유 미기록).
- **방문 여부 null은 3-state로**: Y/N/null을 boolean으로 접으면 "미입력"이 "불가"로 읽혀, 예약 가능한 곳이 불가로 뜰 수 있다. Y/N/UNKNOWN으로 둔다 → [[화면이-아는-만큼만-말하기]]
- **한글 키는 영문 매핑 레이어를 거친다**: 한글 JSON 키는 DB 컬럼·코드 식별자로 쓰기 어렵고, 원본 키가 바뀌면 그 레이어만 고치면 된다.

## 언제 쓰나 (상황 예시)
- 전국 방문 가능 양조장 목록과 지역 필터가 필요할 때.
- 양조장 단위 서비스에 주종·제품 정보를 붙일 때 ([[전통주정보-api]]와 조인).

## 실습에서 배운 것 / 트러블슈팅
- **401 오류**: 원인은 활용신청을 하지 않은 것이었다. 공공데이터포털에서 해당 API 활용신청을 마쳐야 키가 통한다.
- **null이 많다**: 예약방문 null이 31/59다. null이 "미개방"인지 "미입력"인지는 소스 확인이 남은 일로 적혀 있다.
- **홈페이지 필드가 들쭉날쭉하다**: 한글 도메인, punycode(`xn--`), 인스타그램·스마트스토어 링크가 섞여 있고 null도 있다. 8/14에 59곳 전부 접속해 보니 홈페이지가 있는 58곳 중 4곳이 열리지 않았다. 원본이 2024년 12월 기준이라 그 사이 도메인이 만료된 것으로 보인다 → [[관광데이터-공모전]]
- **조인 안 되는 곳**: 3곳은 [[전통주정보-api]]에 제품이 없거나 표기가 달라 매칭에 실패했다(표기 차이 2, 미등록 1). 1곳은 매칭됐지만 제품 텍스트에 주종 키워드가 없었다. 이 4곳은 주종 탭에 안 뜨므로 수기 보정이 필요했다 → [[수기-보정-레이어]]
- **여러 주종을 만드는 양조장이 많다**: 조인된 56곳 중 3종 13 · 2종 16 · 1종 26 · 0종 1. 절반 가까이(29곳)가 2종 이상이라 한 양조장이 여러 탭에 중복으로 뜬다는 전제로 UI를 짜야 한다.
