## 한 줄 정의
AWS에서 가상 컴퓨터 한 대(인스턴스)를 빌려 쓰는 서비스다. [[띵동]]은 EC2 한 대에 Nginx → Gunicorn → Flask 서버를 올리고 YAMNet 추론과 STT 호출을 처리할 계획이었다.

## 핵심 내용
- **인스턴스**: EC2에서 빌린 가상 컴퓨터 한 대. 유형마다 CPU·RAM 사양이 다르다 (t2.micro 1GB, t3.small 2GB).
- **리전**: 어느 나라 데이터센터를 쓸지 고르는 것. 기기와 서버가 가까울수록 지연이 짧다.
- **가입 정책 변경**: 2024년 7월부터 신규 가입자는 플랜을 고른다. 무료 플랜(200 USD 크레딧, 6개월, 유료 전환 안 하면 자동 해지) 또는 유료 플랜이다. 예전 자료의 "12개월 프리 티어"는 신규 가입에 적용되지 않는다.

## 언제 쓰나 (상황 예시)
- Docker 없이 Python 웹 서버([[flask]])를 바로 올리고 싶을 때.
- TensorFlow 같은 무거운 라이브러리를 작은 인스턴스에 올리기 전, 워커 수 × (라이브러리 + 모델 + 앱) 메모리를 먼저 계산할 때.
- 기간이 정해진 프로젝트: 서버를 띄우는 시점과 무료 플랜 만료일을 맞춰 본다.

## 실습에서 배운 것 / 트러블슈팅
- **고른 이유 (2026-04-07)**: GCP Cloud Run과 비교해 EC2를 택했다. 한국어 레퍼런스가 많고, Docker 없이 Flask를 바로 올릴 수 있고, AI 도구로 작업하기 수월하다. 서울 리전은 "5초 이내 알림"에 유리하다.
- **t2.micro → t3.small (2026-04-30)**
  - TensorFlow 공식 이슈 #36459: `import`만 해도 RSS가 47.6MB → 340.2MB로 뛴다. t2.micro에서 Flask+Gunicorn이 OOM kill된 사례도 여럿 있었다.
  - Gunicorn 워커 2개 기준 추정: 워커당 TF 340MB + 모델 50MB + Flask/STT 80MB ≈ 470MB. 워커 2개 + 마스터 ≈ 1.0~1.2GB. t2.micro(1GB)는 swap이 없으면 거의 확정 OOM이다.
  - 시연 중 OOM 한 번이면 끝이라 t3.small(2GB)로 정했다. 추가 비용은 월 9,000원, 6개월 54,000원.
  - 이후 방향(2026-05-06): t3.small + 워커 2개 + `preload_app=True`. 실제 메모리는 PoC에서 잰다. 나중에 잰 값은 [[yamnet]] 참고(peak 489MB / 2048MB).
- 인스턴스 크기는 모델 파일 크기가 아니라 **프레임워크 import 비용 × 워커 수**가 정한다.
- **저장소**: 이미지는 EC2 로컬 디스크에 30일 보존한다. EBS 8GB로 충분하다고 계산했다(2026-04-29).
- Whisper 자체 호스팅도 검토했지만, 한국어에서 쓸 만한 모델은 t2.micro·t3.small에서 OOM이라 제외했다 → [[asr]]
- **가입과 보안 설정 (2026-05-13)**: t3.small을 11주차(7/26+)에 띄울 예정이라 무료 플랜으로 충분했다. 가입 직후 보안 설정 4종을 먼저 했다.

| 항목 | 설정 |
|---|---|
| MFA | OTP 앱 등록 + 시크릿 키 별도 백업 |
| IAM 사용자 | 작업용 사용자 생성(`<REDACTED>`). 이후 작업은 IAM 사용자로 하고 root는 봉인 |
| Budget — Zero-Spend | $0.01 초과 시 알림 |
| Budget — Monthly | 월 $100 기준, 85% / 100% 단계 알림 |

- Zero-Spend Budget을 따로 두는 이유: "모르는 사이 켜진 리소스 과금"이 가장 무서운 시나리오다. 1센트만 넘어도 알림이 오면 그날 안에 잡을 수 있다.
