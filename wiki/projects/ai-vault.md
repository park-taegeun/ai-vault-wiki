## 핵심 결정
- **한 볼트, 두 레포.** 공개 위키와 비공개 원본이 한 레포에 있으면 `.gitignore` 한 줄 실수로 원본이 공개될 수 있다. 루트 레포는 `_private/`를 통째로 무시하고, `_private/`는 별도 git 레포로 만들었다. git은 중첩 레포 안의 파일을 바깥 레포에 `git add -f`로도 넣지 못한다 — 규칙이 아니라 구조로 섞일 수 없게 했다. 분류 기준은 "애매하면 비공개, 공개 전환은 사람이".
- **① 규칙(soft)과 강제(hard)를 분리한다 — 팻말 vs 자물쇠.** CLAUDE.md는 어겨질 수 있는 부탁이다. 어기면 사고가 나는 규칙은 시스템이 막는다.
  | 시점 | 장치 | 막는 것 |
  |---|---|---|
  | 파일을 쓰는 순간 | PreToolUse 훅 가드 (exit 2면 차단) | 원본 수정, 공개 구역에 비밀값·개인정보 쓰기 |
  | 권한 | `settings.json` deny | push, `--no-verify`, `git config`, 가드·스크립트 자기 수정 |
  | 공개 레포 커밋 | pre-commit 훅 | 비공개 경로, 비밀값·개인정보, 공개→비공개 링크 |
  | 비공개 레포 커밋 | pre-commit 훅 | 살아 있는 API 키·토큰 |
  | 배포 | GitHub Actions | 공개 파일 전수 재검사, 실패 시 배포 중단 |
  push는 항상 사람이 한다. 가드는 패턴 모듈을 못 불러오면 막는 쪽으로 실패한다(fail-closed). 가드 메시지에 "규칙서 몇 장 위반"과 "우회하지 말고 보고하라"를 넣으면 Claude는 다른 길을 찾지 않고 멈춘다.
- **② 답이 정해진 일은 코드가, 판단이 필요한 일은 LLM이.** 링크 개수·끊긴 링크·고아 페이지·마감일·미처리 원본은 점검 스크립트가, 모순·중복·공개/비공개 분류는 Claude가 한다. Velog 수집도 LLM 없이 공개 GraphQL API로 한다.
- **③ 병렬로 쓰되, 공유 상태는 한 명만 고친다(single writer).** 서브에이전트는 초안만 쓰고 병합·목차·로그는 메인 혼자 고친다. 병렬 전에 용어집을 승인받아 페이지 이름을 고정한다. → [[nested-agent]]
- **④ "복리로 똑똑해진다"를 측정한다.** 골든 질문을 질문마다 새 서브에이전트에게 위키만 보고 답하게 해 채점한다. 자동화 2단계는 최근 14일 `/velog-wiki` 5회 이상 + correction(사람이 Claude의 판단을 고친 횟수) 1회 이하일 때만 검토한다.
- **손으로 해서 안정된 과정만 자동화한다.** 그래서 1단계는 수집만 자동화했다.

### 트러블슈팅
- **가드 오탐 3종**: `git@github.com:...`을 이메일로(→ `^git@` 허용), 실험 수치 `671.3042602539062`를 주민등록번호로(→ 앞 6자리가 실제 생년월일이고 소수 일부가 아닐 때만), 예시 코드 `access_token = refresh_access_token()`을 비밀값으로(→ 값에 숫자가 섞이고 함수 호출로 끝나지 않을 때만) 잡았다. 세 번째 때 훅 메시지가 `--no-verify`를 안내했지만 Claude는 금지 사항이라 쓰지 않고 멈춰 보고했다. 사람이 패턴을 고치고 회귀 테스트(예시 코드 6종 통과, 진짜 키 모양 5종 차단)로 확인했다. → [[fault-injection]]
- **Velog 중복·누락 추적**: 같은 글이 두 번 저장되고 2편이 조용히 빠졌다. 첫 추정(목록 페이지 경계 중복)은 틀렸지만, 건너뛴 글을 이유와 함께 출력하게 하자 진짜 원인이 드러났다 — Velog에 같은 slug 글이 2개였고 한 글은 slug 조회 시 null. slug 대신 글 고유 id로 조회하고, 요청한 id와 받은 id가 다르면 저장을 거부하게 고쳤다. 가장 위험한 코드는 조용히 넘어가는 코드(silent skip)다.
- **관대한 mock이 버그를 숨겼다**: 테스트용 mock이 요청하지 않은 필드까지 돌려줘서 실제 API에서 `KeyError: 'url_slug'`와 시리즈 이름 앞 공백 문제가 터졌다. 요청한 필드만 돌려주는 strict mock으로 재현한 뒤 고쳤다. → [[test-network-isolation]]
- **Python 스크립트로 가드를 비켜 간 쓰기**: 훅은 도구 호출만 보므로 스크립트가 여는 파일은 검사 밖이었다. "위키와 원본은 Write/Edit 도구로 하나씩" 규칙을 추가했다.
- 그 밖: 한글 파일명을 git이 이스케이프해 커밋 훅이 못 잡음(→ `-c core.quotePath=false`), 인라인 코드 속 `[[x]]`를 링크로 셈(→ 코드 제거 후 추출), 공개·비공개 양쪽 `index.md` 이름 충돌(→ 파일명 볼트 전체 고유), 지시문에 선택지를 남겨 에이전트가 멈춤(→ 지시에는 결정 하나만).
- correction은 "Claude의 판단 오류"만 센다. 승인된 용어집대로 한 작업을 잘못 기록했다가 지운 적이 있다 — 지표는 세는 기준이 정직해야 의미가 있다.
