## 한 줄 정의
폴더 이름·파일 이름을 클래스 정답으로 믿지 않고, 학습 데이터에 실제로 붙은 라벨과 소리를 다시 들춰 이름표가 내용물과 맞는지 확인하는 일이다.

## 핵심 내용
- 이름표는 내용물을 보증하지 않는다. 폴더 이름은 수집 스크립트가 붙인 이름표일 뿐이라, **그 이름표를 붙인 코드**까지 거슬러 올라가야 맞는지 안다.
- 순서는 라벨 대조가 먼저, 귀로 듣는 청취는 확인용이다.
- 수천 조각을 다 들을 수 없으면 모델 점수로 확실한 쪽을 자르고 애매한 회색 구간만 듣는다. 단, 거르는 도구도 **우리 녹음에 먼저 대 보는 대조군**이 필요하다.
- 정답 이름표가 틀리면 모델은 틀린 문제를 잘 푼다. 높은 점수가 맞는 문제를 풀었다는 뜻은 아니다.
- **귀는 성격을, 계수는 규모를 준다**: 귀로는 무엇이 섞였는지 알지만 얼마나 섞였는지는 모른다. 규모는 파일 이름·메타데이터로 센다.

## 언제 쓰나 (상황 예시)
- 재학습 전에 공개 데이터에서 받아 온 구간의 라벨을 확인할 때.
- 특정 클래스 성적이 이상하게 좋거나 나쁠 때.

## 실습에서 배운 것 / 트러블슈팅
- **화재경보 녹음 앞 9초는 사람 목소리였다 (기록 76)**: 음성 합성 소리가 화재 안내 방송과 닮아 화재경보를 흐릴지 귀로 확인하려고, [[띵동]]의 화재경보 학습 조각을 대조군으로 섞어 들었다. 그러다 화재경보 녹음 앞부분에서 사람이 안내 멘트를 말하는 것이 먼저 들렸다. 조각 파일 이름에 시작 시각이 있어, 시작이 9초 미만인 조각을 한 줄로 셌다.

| 항목 | 값 |
|---|---|
| 해당 녹음 수 | 171개 |
| 녹음당 조각 | 3개 |
| 해당 조각 | 513개 |
| 화재경보 학습분 | 1,134개 중 345개 (30.4%) |

  - 이미 관찰하던 "사람 목소리를 넣으면 화재경보로 분류되는 경향"의 **원인 후보**다. 멘트 조각을 빼고 재학습해 본 적이 없어 인과는 입증되지 않았다 → [[out-of-distribution]]
  - 앞서 찾은 데이터 중복(원본 앞쪽 9~10초 동일)의 정체도 이것으로 보인다 → [[data-leakage]]
  - 결정: 파일은 지우지 않고(되돌릴 수 있어야 함) 분할 단계에서 제외했다. 제외 순서도 규칙의 일부다.
    ```
    무음 제거 → 멘트 제외 → 클래스 간 교차 제거 → 중복 제거
    ```
    이 순서로 산술상 남는 파일은 2,264개(멘트 제외 전 2,299개)다.

> [!warning] 확인 필요
> 기록 76의 "해당 조각 513개"와 "화재경보 학습분 1,134개 중 345개"는 서로 다른 모집단(전체 조각 vs 학습분)으로 보이나 원문에 관계 설명이 없다. 남는 파일 수 차이(2,299−2,264=35)가 345와 다른 이유도 원문에 없다.

- **끊긴 메모의 정체부터 묻기 (기록 76)**: 청취 메모 하나가 문장 중간에 끊겨 "입력기 문제인가?"라고 추정했지만, 실은 음성 속 사람의 말을 받아 친 것이었고 3초 조각 경계에서 말이 잘린 것이었다. 끊긴 메모가 데이터가 어떻게 잘렸는지의 증거가 됐다. 이후 메모 칸 이름에 용도(받아쓰기, 소감, 판정)를 박아 두었다.
- "귀로 한 번 더 들어 본다"를 점검 목록에 넣는다. 검사가 보지 않는 방향은 귀가 열려 있을 때 가끔 보인다.
- **「노크」 폴더에 노크가 없었다 (기록 91)**: 공개 데이터 노크 구간 120개의 라벨은 튀김 120, 저음 휘젓기 74, 지글거림 69, 노크 **0**이었다(한 구간에 라벨 여러 개). 원인은 공개 데이터가 아니라 몇 달 전 수집 스크립트의 카테고리 ID가 「튀김」을 가리킨 것이었다. 공개 분류 체계 문서와 이름을 대조해 확인했다.
- **화재 폴더는 상위 범주로 수집됐다**: 121구간 라벨이 경보(상위 범주) 121, 말소리 38, 화재경보 25, 자명종 16, 연기감지기 10, 사이렌 9, 음악 9였다. 화재경보 또는 연기감지기 라벨이 붙은 구간은 32개였다. 초인종은 정상이었다. 「전부 틀렸다」가 아니라 「골라서 틀렸다」.
- **결정 (3초 조각 기준)**: 노크 폴더 329조각은 「기타 소리」로 옮기고, 라벨 없는 화재 211조각은 학습에서 뺐다. 공개 데이터에는 점수 규칙도 적용했다(예: 라벨 있는 화재 19 제외·56 유지) → [[현관-소리-학습-데이터]]
- **함정 1: 거르는 도구도 우리 소리에는 틀린다**: 직접 녹음한 초인종 51개의 초인종 점수 중앙값이 0.0086이었다. 절반 이상이 0.01 미만이라 점수 규칙을 직접 녹음에는 쓰지 않았다.
- **함정 2: 노크는 점수로 못 거른다**: 점수 0.0093짜리가 실제 문 노크였다. 「끝이 무음이면 노크가 아니다」 가설은 끝이 무음인 17개 중 문 노크 12개로 반박됐다.
- **그동안의 노크 성적**: 기존 모델 test 노크 정답 73/93 중 39개가 노크 라벨 없는 조각(튀김)을 맞힌 것이었다. 오염 출처를 빼고 센 관찰값은 노크 34/49, 초인종 20/22, 화재 139/140이다(공식 지표 아님) → [[모델-교체-판단]]
- **한계**: 청취는 한 명이 노트북 스피커로 3초 조각 단위로 했다. 화재경보와 차 경보·사이렌은 귀로 구분하지 못했다. 「깨끗하게 정제했다」고 말할 수 없다.
