## 한 줄 정의
원본 데이터를 변형해 학습 샘플을 늘리고, 실제 환경의 변화(속도·소음·음량)에 모델을 익숙하게 만드는 기법이다.

## 핵심 내용
[[띵동]] 오디오 증강 전략 (2026-04-28 확정):

| 기법 | 파라미터 | 적용 대상 |
|---|---|---|
| time-stretching | ×0.85, ×1.15 | 전체 |
| background noise | SNR 10/20dB | 초인종·노크 |
| background noise | SNR 25/35dB | 화재경보 |
| volume scaling | -6dB | 전체 |
| pitch-shifting | -2/+2 semitone | 한국 환경음만 |
| SpecAugment | freq_mask=10, time_mask=5 | 전체 (학습 시 on-the-fly) |

- 서양 클립은 원본 포함 8개, 한국 클립은 원본 포함 10개로 만든다.
- 증강 후 추정 학습량: 초인종 ~4,400, 노크 ~7,500, 화재경보 ~16,000.

## 언제 쓰나 (상황 예시)
- 직접 녹음이 비싸고 공개 데이터가 적은 클래스를 보강할 때.

## 실습에서 배운 것 / 트러블슈팅
- **증강은 불균형을 키울 수 있다**: 원래 많던 화재경보가 더 많아져 화재경보:노크:초인종이 약 6.7:3.3:1이 됐다. 그래서 `class_weight`가 필수이고, 한국 환경음에는 `sample_weight` 1.5~2.0배를 줄 예정이었다.
- train/val/test는 파일 단위로 나눈다. 같은 원본에서 나온 클립이 양쪽에 들어가면 [[data-leakage]]다.
- **pitch shift: 지금 켤 수 있는 게 정답은 아니다 (기록 43)**
  - 방향은 "한국 환경음에만 pitch shift"였다. 그런데 지금 가진 한국 소리는 규격 화재경보음뿐이었다.

  | 클래스 | f1 | class_weight | 지금 걸 수 있나 / 실익 |
  |---|---|---|---|
  | 초인종 | 0.736 | 2.10 | 필요하지만 데이터가 아직 0 |
  | 노크 | 0.881 | 1.31 | — |
  | 화재경보 | 0.927 | 0.57 | 걸 수 있지만 최강 클래스라 실익 없음 + 규격음(ISO 8201 계열) 왜곡 위험 |

  - 결론: 대상은 직접 녹음 클립만, 실행은 녹음이 들어온 뒤로 미뤘다.
  - 매칭 로직은 파일명 부분문자열(`any(m in stem for m in markers)`)인데 직접 녹음 파일명 규칙이 없었다. 에이전트가 마커를 추측하지 않고 멈췄다. 짐작으로 넣었다면 에러 없이 pitch 0건으로 남는 잠복 버그가 됐을 것이다 → [[ai-산출물-검증]]
  - 처리: 명명 규칙을 `direct_` 접두사로 확정했다(`direct_doorbell_001.wav` 식). 마커 값은 비워 두고 "녹음이 들어오면 `("direct_",)`로 한 줄 교체하면 활성화"라는 주석을 남겼다. 공개 데이터에는 `direct_`가 없어 화재경보는 구조적으로 자동 제외된다.
  - 대상 0건이 지금은 정상 상태라 경고 로그를 `log.warning` → `log.info`로 낮췄다.
- **SpecAugment: 미적용 유지 (기록 43)**: 모델이 waveform을 통째로 받는 구조라 지금 경로엔 스펙트로그램 마스킹을 끼울 자리가 없다. 데이터가 적을 때 켜면 오히려 학습을 방해한다. "지금은 미적용, 데이터가 늘면 A/B로 결정"을 배선 지점 주석으로 남겼다 → [[single-source-of-truth]]
- 증강 파라미터는 보조 수단이다. 진짜 병목은 데이터 절대량, 특히 가장 약한 초인종의 녹음량이었다.
