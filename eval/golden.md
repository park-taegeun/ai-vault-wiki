# 골든 질문 — 공개 위키

위키가 잘 쌓이고 있는지 확인하는 고정 질문입니다. `/eval`이 질문마다 새 에이전트로 답하게 하고 채점합니다.
처음엔 아래 예시 3개로 시작하고, 위키를 넣으면서 **10개 안팎**으로 늘립니다. 질문은 한 번 정하면 바꾸지 않아야 점수 추이를 비교할 수 있습니다.

> 기대 페이지 이름은 실제로 만들어진 페이지 이름에 맞춰 고쳐주세요.

## Q1
- 질문: Firecrawl MCP로 큰 문서 사이트를 수집할 때 크레딧을 아끼는 순서는?
- 기대 페이지: `firecrawl-mcp`
- 핵심 사실: map으로 URL 구조를 먼저 파악한 뒤 필요한 경로만 crawl한다

## Q2
- 질문: Slack MCP에서 `not_in_channel` 오류가 나면 원인과 해결은?
- 기대 페이지: `slack-mcp`
- 핵심 사실: 권한 문제가 아니라 봇이 채널에 초대되지 않은 것 — 채널에 봇을 초대한다

## Q3
- 질문: 같은 MCP 서버를 local과 user 스코프에 중복 등록하면 어떤 문제가 생기고 어떻게 고치나?
- 기대 페이지: `mcp-scope`
- 핵심 사실: -32000 오류 — 제거 후 npx 캐시를 비우고 user 스코프로 다시 등록한다
